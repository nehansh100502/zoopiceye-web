# ZoopicEye Web 👁️

ZoopicEye is a **production-deployed web application** built using **JavaScript and Node.js**, designed with a modular frontend–backend structure and deployed on **Vercel**.

🌐 **Live Demo:** https://zoopiceye-web.vercel.app

This project showcases real-world development practices, deployment workflows, and structured project architecture.

---

## ✨ Features

- Modular frontend & backend architecture
- Clean and maintainable JavaScript codebase
- API-based communication
- Production deployment on Vercel
- Environment-based configuration
- Scalable folder structure
